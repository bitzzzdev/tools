# Security Policy

## Supported Versions

Security updates are applied to the latest commit on the `main` branch.

| Version | Supported |
|---|---|
| main | Yes |
| < 1.0.0 | No |

## Reporting a Vulnerability

If you discover a security vulnerability in any tool or extension in this repository, please do not open a public issue.

Report vulnerabilities by emailing [CONTACT EMAIL] with:

1. The affected tool or extension name.
2. A description of the vulnerability and its potential impact.
3. Steps or a proof of concept to reproduce the issue.

Maintainers will acknowledge receipt within 48 hours and work on a fix before public disclosure.

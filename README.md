## Tools overview

### AI Chat Exporter (`chat-exporter`)
A browser extension (Manifest V3) that exports conversations directly to Markdown, PDF, JSON, or Plain Text. Includes native session API integration for Claude.ai (full message branches without DOM virtual scrolling truncation) and DOM selectors for ChatGPT and Gemini.

- See [`chat-exporter/README.md`](chat-exporter/README.md) for install and usage instructions.
